# Books for Dad

A standalone Hindi and Punjabi book-summary HTML app for personal and family learning.

## Features

- Hindi/Punjabi language toggle
- Hindi and Punjabi summaries for six books
- Search by title, author, or topic
- Category filters
- Original educational summaries
- Reading progress saved privately in the browser
- Hindi/Punjabi text-to-speech support where the browser provides a matching voice
- Mobile-friendly, no installation required
