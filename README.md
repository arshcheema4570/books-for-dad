# Books for Dad

A standalone, offline-friendly micro-learning and book-summary app for personal and family learning.

## Features

- English, Hindi, and Punjabi language modes
- Book library with search and category filters
- Short “blink” summaries with key takeaways and practical experiments
- Focused reader view with progress navigation
- Browser text-to-speech with language-aware voice fallback
- Playback controls, speed cycling, and sleep timer
- Saved summaries and reading progress stored privately in the browser
- Dark, sepia, and elder-friendly reading modes
- Mobile-friendly, no installation required

## Running locally

Open `index.html` directly in a modern browser, or serve the folder with any static HTTP server.
