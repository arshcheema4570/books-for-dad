# Books for Dad

A standalone Hindi book-summary HTML app for personal and family learning.

## Features

- Hindi interface
- Search and category filters
- Six original educational book summaries
- Reading progress saved privately in the browser
- Hindi text-to-speech support
- Mobile-friendly, no installation required
