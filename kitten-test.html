What this is testing. The Web SDK (v0.1.0, pinned commit c846fe9) serves the v1 Nano int8 — 15M params, ~25 MB download — not the newer v2 Nano int4 (~8.8 MB). So the size win vs Phonon 31M (~35 MB) is roughly 30%, not 4×. The v2 punctuation bug does not apply to this build; the punctuation sentence above still checks pauses directly. Analytics is off (analytics: false). The model comes from Hugging Face on first load and is cached in the browser; ONNX runs single-threaded, so no special headers are needed. English only — Hindi stays on the device voice, unchanged.
