What this is testing. The Web SDK (v0.1.0) only ships the v1 models, so this page loads the v2 Nano int4 files (17M params, 8.8 MB per language, 24 kHz, Apache 2.0) through the SDK's modelFiles override. The v2 graph takes the exact same inputs as v1 (input_ids / style / speed) and uses the same v1 phonemizer and token table — verified locally: “Hello, world.” produced a clean 1.65 s waveform under ONNX Runtime 1.32 before this page was built. One adapter was needed: the SDK looks voices up by v1 keys, so the v2 voice pack was remapped (Eleanor→Bella, Otis→Jasper, Martha→Luna, Vincent→Bruno, Serena→Rosie, Max→Hugo, Grace→Kiki, Danny→Leo); the picker above shows the real v2 names. Int4 needs ONNX opset 21 — the SDK's runtime (1.24.3) covers it, but the phone is the real check. The v2 model names its timing output durations, not duration, so word timings are unavailable — playback is unaffected. Analytics is off (analytics: false). English only — Hindi stays on the device voice, unchanged.
